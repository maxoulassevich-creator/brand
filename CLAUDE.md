## Фирменный стиль

Точные значения взяты из SVG логотипа, не на глаз:

- Тёмно-зелёный `#112A1D` — основной
- Терракота `#DD5835` — акцент
- Айвори `#FFFEE9` — фон
- Заголовки: **TT Wellingtons Medium** · Основной набор: **TT Tricks Regular** (обе с typetype.ru)

Логотип — ретро-гротеск с характерной буквенной пластикой, символ: барашек / корова / бутылка
силуэтами. Паттерны — диагональная решётка с иконками (сыр, рыба, банка, скот).
Важное следствие для выбора макетов: **типографические макеты подхватывают этот стиль лучше,
чем макеты, построенные на фотосетке.**

## Проект

Интернет-каталог на **WordPress + WooCommerce**. Ключевое из ТЗ:

- Двойной режим: публичная витрина для физлиц (**без корзины**) + закрытый оптовый кабинет
  с ручным подтверждением, корзиной и счётом на предоплату. Онлайн-оплаты нет.
- Раздел 11 — **19 страниц** структуры сайта.
- П. 12.1 — 9 категорий: сыры, мясные деликатесы, рыбные деликатесы, закуски и антипасти,
  десерты, чай/кофе/бакалея, безалкогольные напитки, подарки и наборы, алкогольная витрина.
- П. 12.2 — поля карточки товара: состав, страна, регион, производитель, хранение, срок годности,
  вкусовое описание и сочетания. Текста много, карточка должна его вмещать.
- Раздел 20 — зона второго этажа для посетителей (отдельная страница + блок на главной).
- Раздел 21 — у алкоголя в публичном режиме **нет кнопки «в корзину»**, только информация.
- Раздел 23.2 — обязательна мобильная версия.

## Текущая задача

Подобрать на **Envato Elements** Figma-макеты под этот каталог. Критерий заказчика:
макет должен выглядеть **эксклюзивно и креативно, это должно быть заметно**. Точное совпадение
по сфере и по цветам не требуется — цвета заказчик перекрасит под фирменные сам.

**Сделано (редакция 2, превью просмотрены):** `Подбор макетов Envato (Figma).md` — новый топ-6,
скелеты, доноры по экранам, раздел «вычеркнуто и почему», чек-лист.
Веб-версия с картинками: https://claude.ai/code/artifact/7b900b92-7def-47c9-ba43-eb5f0fa47abf

Оговорка первой редакции снята: просмотрено около 60 макетов. Итог — топ пересобран:
Aurelle Atelier, Valente, Knead, LuxDin, Savoria, Aurelian. Вылетели O Brand, Vinoteca, Boskery,
Eline, Goodmeat. Anvogue и Modave переведены в «скелеты», EcoSen — в доноры карточки товара.

**Главный вывод:** фирменный стиль FOODBEER — светлый, типографический, ретро-гротескный,
а весь премиум-фуд на Envato — тёмный с фотографией и курсивной антиквой. Поэтому светлые
макеты на айвори с крупной типографикой поднялись, тёмно-мясные вылетели.

### Как смотреть Envato из этой среды

`curl` на `elements.envato.com` ловит Cloudflare-челлендж (403), Chromium через egress-прокси
не поднимает TLS. Рабочая связка:

1. Страницу товара или тега читать веб-фетчем, попросив **скопировать URL картинок дословно,
   вместе с `?w=…&s=…`** — без подписи `s=` CDN отдаёт 403 «Wrong signature».
2. Картинки качать обычным `curl` с `elements-resized.envatousercontent.com` — этот хост открыт.
3. Склеивать в контактный лист (Pillow) и **смотреть как изображение** — веб-фетч картинок не покажет.
4. Страница тега вида `/graphic-templates/websites/<тег>/compatible-with-figma` отдаёт до 48 товаров
   с обложками за один запрос — самый дешёвый способ триажа.
5. У части товаров галереи превью нет вообще, только обложка 433 px. Это надо отмечать в выводах.

**Следующий шаг:** заказчику выбрать из топ-6. После выбора — разложить 19 страниц раздела 11 ТЗ
по связке «характер + скелет» и проверить выбранный макет по чек-листу.

**foodwine.store на сегодня** — одностраничная заглушка (статический HTML, не WordPress):
логотип, абзац про гастромаркет, телефон, адрес, Telegram и Instagram. Каталога нет.
